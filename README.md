# O Watch

ODEPC (`odepc.kerala.gov.in`) മാത്രം നിരീക്ഷിക്കുന്ന പ്രത്യേക പ്രൊജക്റ്റ്.

ഏത് രാജ്യത്തും ആർട്ട് ടീച്ചർ തസ്തികയുടെ വിവരം വന്നാൽ ആപ്പ് മുഴുവൻ ചുവക്കും, ബ്രൗസർ അറിയിപ്പും വരും. അതുവരെ ആപ്പ് പച്ചയാണ്.

ഇത് `kalashala` അല്ല, `FieldTrace` അല്ല. ആ രണ്ട് റിപ്പോകളിലും ഈ കോഡ് ചേർത്തിട്ടില്ല.

ഫോണിന്റെ ഹോം സ്ക്രീനിൽ ഇൻസ്റ്റാൾ ചെയ്യാം. ഐക്കൺ വലിയ അക്ഷരം **O**. പബ്ലിഷ് ചെയ്ത ലിങ്ക് ഫോണിലെ ബ്രൗസറിൽ തുറന്ന് **ഇൻസ്റ്റാൾ ചെയ്യുക** അമർത്തുക.
